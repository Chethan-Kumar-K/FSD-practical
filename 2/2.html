          The HTML5 APIs behind this page

          Each API is here because the tracker needs it. The last column runs a feature check in your browser right now.

          HTML5 APIs used in this application, where to try them, and browser support
          API What it does here Where to try it In this browser
          Web Storage localStorage keeps your log, pledges and reminder settings between visits. sessionStorage keeps the unsent form in this tab. Add an entry, then reload the page.
          Geolocation Measures the distance of a trip so you do not have to guess kilometres. Log Activity, Measure a trip with GPS.
          Canvas Draws the category donut and the 14-day bar chart with the budget line. Insights. Hover a bar.
          Drag and Drop Moves suggested changes into your pledges and back. Also accepts a backup file dropped on the import area. Pledges. My Log, import area.
          Web Workers Totals your log and ranks the reduction ideas on a background thread, so the page stays responsive with a large log. Insights, note under the stats.
          Notifications Reminds you to log, and warns when a day goes over budget. Log Activity, Daily reminder.
          File API with Blob and URL FileReader reads an imported backup. Blob and object URLs build the CSV and JSON downloads. My Log, Back up or move your log.
          Web Share and Clipboard Shares your 30-day summary through the phone’s share sheet, or copies it. Insights, Share my summary.
          Constraint Validation Checks the amount and date with the browser’s validity states, then shows plain-language messages. Clear the amount, or type a very large one.
          Intersection Observer Highlights the current section in the navigation as you scroll. Scroll the page.

          Semantic HTML5 elements used: header, nav, main, section, aside, footer, figure and figcaption, time, output, meter, details and summary, dialog, and the date, time, number and file input types.
